# Myanmar POS System

This project is a Point of Sale (POS) system tailored for use in Myanmar. It provides a user-friendly interface for managing purchases, sales, inventory, and bank statements.

## Project Structure

```
myanmar-pos-system
├── src
│   ├── index.html          # Main entry point of the web application
│   ├── purchase.html       # Page for processing purchases
│   ├── sales.html          # Page for managing sales transactions
│   ├── inventory.html       # Page for inventory management
│   ├── bank-statements.html # Page for viewing bank statements
│   ├── css
│   │   └── styles.css      # CSS styles for the application
│   ├── js
│   │   └── scripts.js      # JavaScript for handling interactions
│   └── assets
│       └── fonts           # Directory for font files
├── README.md               # Project documentation
└── package.json            # npm configuration file
```

## Features

- **Purchase Management**: Easily process and track purchases.
- **Sales Tracking**: Record and display sales transactions.
- **Inventory Control**: Manage stock levels and product information.
- **Financial Overview**: View and manage bank statements and financial records.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd myanmar-pos-system
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open `src/index.html` in a web browser to start using the application.

## Usage

- Navigate through the application using the links provided in the main interface.
- Use the purchase page to add new purchases.
- Access the sales page to record sales transactions.
- Manage inventory through the inventory page.
- Review financial records on the bank statements page.

## Future Enhancements

- Additional features may include user authentication, reporting tools, and integration with payment gateways.
